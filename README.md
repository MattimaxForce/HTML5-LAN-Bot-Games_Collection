## 🇮🇹 Italiano

Una raccolta curata di videogiochi browser-based leggeri, immediati e autocontenuti in singoli file HTML. Ciascun titolo integra intelligenza artificiale per giocare in modalità solitaria contro i Bot e funzionalità multiplayer locale (LAN/P2P via WebRTC o PeerJS) per sfidare amici nella stessa rete senza bisogno di server dedicati o configurazioni complesse.

### ⚡ Come si gioca (Zero Installazione)

1. **Scarica i file**: Puoi scaricare l'intero archivio della repository (tasto verde `Code` -> `Download ZIP`) oppure scaricare singolarmente il file `.html` del videogioco a cui vuoi giocare.
2. **Apri nel browser**: Fai doppio click sul file HTML o trascinalo in qualsiasi browser moderno (Chrome, Firefox, Edge, Safari, Brave).
3. **Nessun server richiesto**: Non serve Node.js, né server web o estensioni: il gioco parte istantaneamente in locale!

### 🕹️ I Giochi della Collezione

#### 1. 🏰 Rival Realms: RPG Tycoon & Sabotage (`RivalRealms.html`)
- **Genere**: RPG Gestionale / Azione Competitiva / Sabotaggio in tempo reale.
- **Caratteristiche**:
  - Esplora la tua tenuta medievale, estrai cristalli dalla Fonte sacra e convertili in oro presso la Fucina.
  - Sblocca operai PNG automatizzati e raccoglitori d'oro passivi.
  - Meccanica di **Sabotaggio**: calpesta gli altari oscuri per lanciare goblin predatori, rocce bloccanti o maledizioni rallentanti nella tenuta dell'avversario.
  - Combattimento diretto con la spada contro mostri e ostacoli.
  - **Modalità**: Split-Screen contro un Bot intelligente oppure Multiplayer LAN P2P a schermo intero (2+ giocatori con architettura a inviti WebRTC).

#### 2. 👑 Rival Realms: Deluxe Edition (`RivalRealms_Deluxe.html`)
- **Genere**: RPG Tycoon Evoluto / Strategia / Gestione della Tenuta.
- **Caratteristiche**:
  - Edizione arricchita con grafica dettagliata, sprite umanoidi animati (con occhi espressivi, passi sincronizzati ed equipaggiamento personalizzato).
  - **Emporio Reale & Mercante Live**: un negozio interattivo dedicato dove assumere Minatori nani (con elmetto e piccone), Portatori veloci e Cavalieri di Guardia armati di spada che pattugliano la tenuta e combattono i nemici in autonomia.
  - Sistema di Rinascite (*Rebirth*), frutteti dorati e sabotaggi avanzati via WebRTC.
  - **Modalità**: Partita contro Bot in Split-Screen o Multiplayer LAN ad alta sincronizzazione.

#### 3. ⚡ Cyber Arena: Neon Showdown (`Cyber_arena_neon_showdown.html`)
- **Genere**: Top-Down Arena Shooter / Fantascienza Cyberpunk.
- **Caratteristiche**:
  - Duelli al fulmicotone a tema neon tra due piloti cybernetici.
  - Fisica balistica con proiettili riflettenti/traccianti, dash ad alta velocità per schivare attacchi e coperture tattiche distruttibili.
  - Sistema di Power-up dinamici: colpo triplo, scudi energetici al plasma, cure rapide e turbo sprint.
  - Effetti sonori procedurali sintetizzati in tempo reale con le Web Audio API.
  - **Modalità**: Connessione LAN P2P ultraveloce tramite PeerJS con codici stanza alfanumerici a 5 caratteri.

#### 4. 🐍 Snake Arena (`SnakeArena.html`)
- **Genere**: Arcade Survival / Snake Battle Royale (fino a 8 giocatori).
- **Caratteristiche**:
  - Reinterpretazione tattica del classico Snake in un'arena a eliminazione diretta.
  - Mangia, cresci fino a 90 segmenti e taglia la strada ai rivali per farli schiantare.
  - Alla morte, i serpenti lasciano scie di cibo trasformando la mappa in una frenetica caccia ai punti.
  - Timer di round, tabellone punteggi in tempo reale, modalità spettatore post-eliminazione e classifica finale con podio.
  - **Modalità**: Partite solitarie o di gruppo aggiungendo bot intelligenti dotati di algoritmi di flood-fill e prevenzione collisioni; supporto multiplayer LAN fino a 8 partecipanti.

#### 5. 💎 Isola Tattica - Gem Hunters (`IsolaTattica.html`)
- **Genere**: Griglia Strategica Turn/Real-Time / Caccia alle Gemme.
- **Caratteristiche**:
  - Sfida a due su un arcipelago con ostacoli naturali e maree.
  - Raccogli gemme comuni e gemme epiche prima che scada il tempo, tagliando le traiettorie dell'avversario.
  - Bot dotato di imperfezioni umane simulate: tempi di reazione ponderati, euristiche di scelta percorso e piccoli margini d'errore realistici.
  - **Modalità**: Sfida rapida vs Bot o connessione diretta P2P LAN tramite scambio codice offerta/risposta WebRTC.

#### 6. 🐝 Sciame: Il Giardino delle Api (`Sciame.html`)
- **Genere**: Gioco da Tavolo Astratto / Controllo Area / Strategia su Mappa Esagonale.
- **Caratteristiche**:
  - Estetica rilassante e ricercata in stile acquerello e botanica vintage.
  - Muovi il tuo sciame di api lungo linee rette sulla griglia esagonale e raccogli il nettare prezioso: ogni esagono lasciato alle spalle sparisce dal tabellone, isolando progressivamente il terreno!
  - Regola del salto tattico su singoli vuoti e blocco strategico delle api avversarie.
  - **Modalità**: Sfida contro Bot euristico o LAN P2P senza server da 2 a 4 giocatori con codice di scambio WebRTC immediato.

## 🇬🇧 English

A curated collection of lightweight, instant, single-file HTML5 browser games. Each title features smart Bots for single-player gaming and local multiplayer capabilities (LAN/P2P via WebRTC or PeerJS) to challenge friends on the same network with zero need for external game servers or complicated network setups.

### ⚡ How to Play (Zero Installation)

1. **Download the files**: Clone/download the full repository as a ZIP archive (`Code` -> `Download ZIP`), or simply download individual `.html` files for the games you want to play.
2. **Open in your browser**: Double-click any downloaded HTML file or drag and drop it into any modern web browser (Chrome, Firefox, Edge, Safari, Brave).
3. **No server setup required**: No Node.js, local web servers, or extensions needed: games run instantly out of the box!

### 🕹️ Games in this Collection

#### 1. 🏰 Rival Realms: RPG Tycoon & Sabotage (`RivalRealms.html`)
- **Genre**: RPG Economy Tycoon / Competitive Action / Real-Time Sabotage.
- **Features**:
  - Explore your medieval estate, gather magic crystals from the Well, and forge them into gold.
  - Hire NPC workers and plant golden trees for passive income generation.
  - **Sabotage system**: Step on dark altars to unleash gold-stealing goblins, obstacle boulders, or slowing curses into your rival's realm.
  - Direct sword combat to defeat incoming monsters and clear obstacles.
  - **Modes**: Split-Screen vs. AI Bot or Full-Screen LAN P2P Multiplayer (2+ players with zero-server WebRTC handshake).

#### 2. 👑 Rival Realms: Deluxe Edition (`RivalRealms_Deluxe.html`)
- **Genre**: Advanced RPG Tycoon / Strategy / Estate Management.
- **Features**:
  - Enhanced edition featuring polished graphics and animated humanoid character sprites (with expressive eyes, walking feet, and custom gear).
  - **Royal Emporium & Live Merchant**: An interactive shop drawer where you can recruit Miner Dwarves (with hardhats & picks), swift Resource Carriers, and Knight Guards who patrol and fight goblins on their own.
  - Rebirth multipliers, golden apple orchards, and full WebRTC synchronization.
  - **Modes**: Split-screen vs Bot or full-screen LAN multiplayer.

#### 3. ⚡ Cyber Arena: Neon Showdown (`Cyber_arena_neon_showdown.html`)
- **Genre**: Cyberpunk Top-Down Arena Shooter.
- **Features**:
  - Fast-paced 1v1 neon duels between cybernetic gladiators.
  - Rich ballistic physics with particle-trailing bullets, tactical dashing, and destructible cover walls.
  - Dynamic arena power-ups: triple shot, plasma energy shields, instant heals, and speed boosts.
  - Procedural 8-bit sound effects synthesized in real time via the Web Audio API.
  - **Modes**: Low-latency LAN P2P networking powered by PeerJS using simple 5-character room codes.

#### 4. 🐍 Snake Arena (`SnakeArena.html`)
- **Genre**: Arcade Survival / Snake Battle Royale (Up to 8 players).
- **Features**:
  - A frantic elimination arena take on the classic Snake game.
  - Eat fruit, grow up to 90 segments, and cut off rivals' paths to make them crash.
  - When snakes die, their bodies dissolve into food trails, triggering sudden feeding frenzies.
  - Live HUD match timer, real-time leaderboard, spectator camera, and final podium rankings.
  - **Modes**: Solo against smart flood-fill bots or LAN multiplayer supporting up to 8 players.

#### 5. 💎 Isola Tattica - Gem Hunters (`IsolaTattica.html`)
- **Genre**: Tactical Grid Movement / Gem Collecting Duel.
- **Features**:
  - Turn-based / real-time movement battle across an island riddled with cliffs and waterways.
  - Race to harvest common and rare gems before the timer runs out while boxing your rival in.
  - Simulated human-like Bot: realistic reaction delays, priority evaluation, and intentional slight error margins.
  - **Modes**: Quick match vs Bot or direct 2-player WebRTC P2P LAN connection.

#### 6. 🐝 Sciame: Il Giardino delle Api (`Sciame.html`)
- **Genre**: Abstract Strategy / Hex-Grid Area Control.
- **Features**:
  - Elegant botanical, watercolor-inspired aesthetic with warm, clean typography.
  - Move your bee swarm in straight lines across hexagonal tiles to gather nectar: each vacated tile collapses and disappears, shrinking the walkable meadow!
  - Tactical gap-jumping mechanics and opponent-pinning strategies.
  - **Modes**: Solo vs heuristic Bot or 2-to-4 player serverless LAN multiplayer.
